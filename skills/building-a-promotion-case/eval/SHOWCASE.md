# Showcase: Building a Promotion Case

> Demonstrates the value of the `building-a-promotion-case` skill pack by comparing
> skill-guided output vs. a vanilla LLM response to the same prompt.

## Test Prompt

> Use `building-a-promotion-case`. I'm a Senior PM at a Series C B2B SaaS company (150 people) and want to get promoted to Staff PM in the June cycle. I led the new enterprise onboarding flow (reduced TTV from 14 days to 3), drove a pricing migration affecting 2,000 accounts, and own the API platform roadmap. My company uses a 6-level IC ladder. My manager is supportive but says I need 'more visible cross-functional leadership.' Build a Promotion Case Pack with an evidence log, ladder-mapped narrative, manager alignment plan, and sponsor/visibility map. Output: Promotion Case Pack.

## Results Summary

| Dimension | Without Skill | With Skill |
|-----------|--------------|------------|
| Structure | Executive summary, evidence log, ladder-mapped narrative, gap analysis, manager alignment plan, sponsor map, timeline, appendix with packet draft | Promotion thesis, expectations map with gaps, evidence log with action items, one-pager promo doc, manager alignment plan with 1:1 scripts, sponsor/visibility map with endorsement templates, risks/open questions/next steps |
| Completeness | Includes a full draft promotion packet the manager can submit and a "what this pack does NOT include" section | Includes an explicit promotion thesis (2-sentence pitch), week-by-week commitment table with dated milestones, and follow-up email templates |
| Actionability | 7 gap-closing actions with timeline; 3-phase plan (foundation, execution, close); visibility calendar by week | 12-week week-by-week schedule with specific dated actions, 1:1 conversation script with exact opening/key ask/close language, endorsement request email template ready to send |
| Specificity | Evidence log notes what to quantify but flags many items as "[X]" placeholders; ladder narrative has bracketed gaps to fill | Evidence log includes specific metric claims (78% TTV reduction, 2,000 accounts) with checkboxes for missing data; expectations map explicitly rates each competency as solid/gap/partial |
| Quality gates | Common failure modes list and "what NOT to include" anti-patterns | Full checklist (pack completeness, evidence quality, ladder alignment, manager readiness, narrative quality) plus a 13/14 rubric self-score |

## Key Differences

1. **Promotion thesis as anchor.** The skill output opens with a crisp 2-sentence promotion thesis that frames the entire case, making it easy for a manager to quote in calibration. The baseline opens with a readiness assessment ("75% ready") which is honest but positions the candidate as not-yet-ready rather than already-operating-at-level.

2. **Conversation scripts.** The skill output includes a word-for-word 1:1 agenda for the manager alignment conversation (opening, thesis share, key ask, criteria agreement, close) plus a follow-up email template. The baseline provides a structured agenda with discussion points but not rehearsable scripts, which matters for high-stakes conversations.

3. **Evidence gap tracking.** The skill output lists specific evidence gaps as checkboxes with deadlines (e.g., "Get exact enterprise activation rate by March 28"), making it a working action list. The baseline identifies the same gaps but frames them as recommendations rather than a tracked to-do list.

4. **Packet draft.** The baseline includes a complete draft promotion packet written as if from the manager's perspective, ready to adapt to the company's template. The skill output includes a one-pager promo doc but does not draft the full manager-submitted packet, which is a genuine advantage of the baseline.

5. **Anti-pattern guidance.** The baseline includes a valuable "Common Failure Modes to Avoid" section (e.g., "assuming the work speaks for itself," "over-indexing on execution, under-indexing on influence") that provides strategic coaching beyond the tactical plan. The skill output addresses risks but does not package this meta-advice as prominently.

## Verdict

Both outputs are strong and cover the same core components. The skill output is more immediately executable -- its dated schedule, conversation scripts, and email templates reduce the gap between "reading the plan" and "doing the work." The baseline adds strategic coaching and a draft promotion packet that the skill output lacks. A candidate would benefit from using the skill output's execution framework while incorporating the baseline's failure-mode awareness and packet draft.
