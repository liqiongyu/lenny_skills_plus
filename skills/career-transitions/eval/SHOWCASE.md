# Showcase: Career Transitions

> Demonstrates the value of the `career-transitions` skill pack by comparing
> skill-guided output vs. a vanilla LLM response to the same prompt.

## Test Prompt

> Use `career-transitions`. I'm a PM with 6 years of experience at a mid-stage fintech company. I'm considering moving into developer relations or product marketing at a developer tools company. I have 8 hours/week for this transition, must stay remote, and my comp floor is $180k. I have a strong writing portfolio (blog + internal docs) and have spoken at 2 conferences. Create a Career Transition Pack with target archetypes for DevRel vs PMM, an option scorecard, outreach scripts for informational interviews, and a 6-week experiment plan to test both paths. Output: Career Transition Pack.

## Results Summary

| Dimension | Without Skill | With Skill |
|-----------|--------------|------------|
| Structure | Role archetypes, option scorecard (user fills in), outreach scripts, 6-week experiment plan, risks, decision framework | Context snapshot, push/pull map, genie goal + 10-year backcast, target archetypes with fit/no-go signals, weighted scorecard, opportunity pipeline plan with 20 contacts, skills/proof plan, 5 experiments with pass/fail criteria, risks/open questions/next steps |
| Completeness | Fit assessments for both paths, comp ranges, scoring rationale, 4 outreach scripts, weekly experiment activities | Adds progress metric definition, "never again" list, 3-year waypoint, 5 skill gaps with learning plans, community immersion experiment, and a "stop doing" list |

| Specificity | Comp ranges with rationale; fit assessment tables per archetype; decision framework with 3 tests (energy, identity, regret minimization) | Weighted scorecard pre-scored (DevRel 4.45 vs PMM 3.70), decision rule with evidence threshold and deadline (April 28), 5 specific unknowns with resolution methods and target dates |
| Quality gates | None explicit | 10/10 rubric self-score across 5 dimensions (clarity, options, evidence, pipeline, execution fit) plus structural checklist |

## Key Differences

1. **Decision framework precision.** The skill output pre-scores the option scorecard with weighted criteria (DevRel 4.45 vs PMM 3.70) and states an explicit decision rule: "choose the path that scores highest after 3+ interviews per archetype and 1 proof artifact per path; if within 0.5 points, use the daily-reality gut check; decide by April 28." The baseline provides a thoughtful 3-test framework (energy, identity, regret minimization) but leaves scoring entirely to the user.

2. **Experiment rigor.** The skill output defines 5 named experiments, each with a goal, steps, pass/fail signals, and which scorecard criteria they update. The baseline's 6-week plan includes comparable activities (content experiments for both paths, community engagement) but frames them as weekly activities rather than hypothesis-driven experiments with defined success criteria.

3. **Pipeline depth.** The skill output specifies a 20-person target contact list (10 DevRel, 10 PMM) with role categories, plus a weekly cadence budget (1.5 hrs outreach, 2 hrs interviews, 3 hrs content, 1 hr community, 0.5 hrs tracking). The baseline identifies the need for outreach and provides strong scripts but does not pre-structure the pipeline list.

4. **Long-term framing.** The skill output includes a "genie goal," 10-year headline, 3-year waypoint, and a push/pull map that connects the transition to deeper career aspirations. The baseline focuses on the 6-week decision window and practical execution, which is arguably more focused but lacks the motivational framing.

5. **Scorecard design.** The baseline's scorecard is interactive -- it lists dimensions with pre-filled rationale but leaves weights and some scores blank for the user to complete, which encourages ownership. The skill output pre-fills the entire scorecard, which is faster to act on but may feel less personalized.

## Verdict

The skill output is more structured and decision-oriented -- its pre-scored scorecard, explicit decision rule, and experiment pass/fail criteria reduce the risk of analysis paralysis. The baseline is more coaching-oriented, with an interactive scorecard and a reflective decision framework that encourages the user to develop their own criteria. For someone who needs to move quickly within 8 hours/week, the skill output's prescriptive approach is higher-leverage; for someone who values self-discovery in the process, the baseline's interactive elements are a strength.
