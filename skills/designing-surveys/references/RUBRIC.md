# Rubric (Designing Surveys)

Score each dimension **1–5** (1 = poor, 3 = acceptable, 5 = excellent). Include notes and a short improvement plan for any score ≤ 3.

## 1) Decision clarity
- **1:** No decision; survey is “general feedback” with no stated outcome.
- **2:** A loose goal exists (“learn about satisfaction”) but no specific decision or deadline.
- **3:** Decision exists but is broad; success criteria are unclear; “what we’ll do if…” scenarios are missing.
- **4:** Decision + deadline stated; success criteria exist but decision thresholds are soft.
- **5:** Clear decision + deadline + explicit “what we’ll do if…” scenarios for different result ranges.

## 2) Audience + sampling quality
- **1:** Audience is vague (“all users”); sampling is unrealistic or undefined.
- **2:** Audience named but only by demographics; no behavioral/recency criteria; sample size not estimated.
- **3:** Audience mostly defined with some behavioral criteria; sample constraints acknowledged; bias gaps noted but not mitigated.
- **4:** Clear cohort definition (behavior + recency); segment cuts planned; sample size justified; most bias gaps documented.
- **5:** Clear cohort definition with stratification; segment cuts planned; bias/coverage gaps documented with mitigation plans; response rate targets set.

## 3) Measurement design (metrics + diagnostics)
- **1:** Metrics are unclear; questions don’t map to any decision or action.
- **2:** A metric is chosen (e.g., NPS) but no diagnostic questions explain the score; no prioritization mechanism.
- **3:** Core metric exists; some diagnostics are actionable; frequency or impact weighting is partial.
- **4:** Metric + diagnostics linked to decisions; prioritization mechanism present; minor gaps in weighting.
- **5:** Metric + diagnostics are tightly linked to decisions; prioritization + frequency/impact weighting produce a ranked output; thresholds for action are predefined.

## 4) Questionnaire quality (clarity + bias control)
- **1:** Leading, double-barreled, or jargon-heavy questions; survey is too long (>10 min); scales are inconsistent.
- **2:** Some clear questions but multiple double-barreled or leading items remain; length is borderline.
- **3:** Mostly clear; a few risky questions remain; completion time is within target; scale consistency is mostly maintained.
- **4:** Neutral, single-concept questions; consistent scales; completion time meets target; minor wording improvements possible.
- **5:** Neutral, single-concept questions; consistent scales; completion time meets target (3-6 min); option randomization where appropriate; “Other” and “N/A” handled intentionally.

## 5) Instrument QA (mobile + logic)
- **1:** Mobile/logic untested; required fields are excessive; no pilot planned.
- **2:** Basic structure exists but mobile rendering unchecked; skip logic is incomplete.
- **3:** Basic QA done; some edge cases remain (e.g., scale point visibility on mobile); pilot is planned.
- **4:** Mobile rendering checked; logic is correct; required fields are minimal; pilot completed or planned with clear criteria.
- **5:** Mobile rendering verified across devices; logic correct and tested; option order and “N/A/Other” handled intentionally; pilot run with results documented.

## 6) Analysis + reporting plan
- **1:** “We’ll look at results” with no predefined plan, cuts, or coding approach.
- **2:** Some segment cuts mentioned but no coding plan for open-ends; no decision thresholds.
- **3:** Segment cuts exist; open-ended coding approach is rough; decision thresholds are directional.
- **4:** Predefined cuts and coding plan; decision thresholds exist; reporting format is drafted.
- **5:** Predefined cuts, coding plan for open-ends, decision thresholds, and a clear reporting format tied to specific actions; statistical considerations (confidence, sample adequacy) addressed.

## 7) Actionability + close-the-loop
- **1:** Results won’t change anything; no follow-up plan; respondents won’t hear back.
- **2:** Some actions vaguely implied; no owner or timeline; respondent follow-up not planned.
- **3:** Some actions implied with rough prioritization; follow-up is vague but acknowledged.
- **4:** Actions tied to result scenarios; owners suggested; respondent follow-up channel identified.
- **5:** Clear owners/next steps for each result scenario; respondents will hear back through a defined channel; results feed into a named planning process.

## 8) Privacy + ethics
- **1:** Sensitive data collected unnecessarily (PII, demographics without purpose); no consent or data handling plan.
- **2:** Some minimization attempted but PII collection is questionable; consent is boilerplate.
- **3:** Basic minimization practiced; consent included; unknowns about retention/access are noted.
- **4:** Minimization is explicit; consent is clear; retention policy defined; most compliance requirements met.
- **5:** Minimization is explicit; consent/retention/review requirements are captured; compliance with relevant regulations confirmed; data deletion timeline specified.

## Suggested overall rating
- **Excellent:** avg ≥ 4.2, no dimension < 4
- **Good:** avg 3.5–4.1, no dimension < 3
- **Needs work:** avg < 3.5 or any dimension < 3
