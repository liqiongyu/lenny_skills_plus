# Showcase: Founder Sales

> Demonstrates the value of the `founder-sales` skill pack by comparing
> skill-guided output vs. a vanilla LLM response to the same prompt.

## Test Prompt

> Use `founder-sales`. Prospects agree there's pain but keep stalling, asking for "more time" or "send info."

## Key Differences

1. **Decision enablement vs. objection handling.** The skill output centers on a key insight: "no decision" is not the same as "no" -- the buyer sees the pain but the path forward feels risky. It provides a 1-page decision guide with 3 options (status quo with quantified cost, DIY, bounded pilot) that the champion can use internally. The baseline focuses on real-time objection responses, which help in conversation but do not give the buyer an internal decision tool.

2. **Prospect tiering for stalled pipeline.** The skill output creates a 3-tier classification system (high/medium/low rescue probability) based on pain quantification, trigger events, and decision-maker access, with different next actions per tier. The baseline provides a qualification framework but does not specifically segment an existing stalled pipeline.

3. **Founder POV with "cost of doing nothing."** The skill output includes a problem-first narrative framing the cost of delay ("every month costs X hours lost, Y errors accumulated"), distinct from product features. The baseline advises quantifying pain during discovery but does not provide a structured narrative the founder can reuse across conversations.

4. **White-glove activation plan.** The skill output defines "activation" (product set up, first workflow processed, buyer confirms value), includes a 30-day success plan with week-by-week milestones, and specifies that the kickoff call should be scheduled during the close, not after. The baseline ends at the deal close without covering activation.

5. **Learning loop with message iteration.** The skill output includes a weekly review template that tracks stall patterns, winning messages, and message variants, creating a feedback loop for improving outreach over time. The baseline lists metrics to track but does not build an iteration system around them.

## Verdict

The skill output is built around a central thesis: stalled deals need decision enablement, not more information or harder closes. Its decision guide, bounded pilot framing, and mutual action plan give the buyer the internal tools to say yes. The baseline is excellent sales coaching that would improve any founder's real-time selling skills, but it is oriented toward conversation technique rather than systemic deal acceleration. For a founder with a pipeline of stalled deals, the skill output provides more immediately deployable tools.
