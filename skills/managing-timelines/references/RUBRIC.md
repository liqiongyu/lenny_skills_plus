# Rubric (Managing Timelines)

Score each item 0/1/2:
- 0 = missing / unusable
- 1 = present but incomplete
- 2 = clear, executable, reusable

Suggested passing bar: **>= 16/20**.

## 1) Deadline clarity (0–2)
- **0:** No date type stated; “why now” is missing; no variable levers identified.
- **1:** Date type exists but justification is weak; variable levers mentioned but not prioritized.
- **2:** Date type is explicit and justified (“why now”); variable levers (scope/resources/quality/date) are named and ranked.

## 2) Commitment ladder (0–2)
- **0:** All dates presented as commitments with no distinction between certainty levels.
- **1:** Commit vs forecast vs target language exists but is used inconsistently; no re-forecast checkpoint.
- **2:** Commit/forecast/target language is defined, used consistently, and includes confidence levels + next re-forecast checkpoint.

## 3) Phase plan + gates (0–2)
- **0:** No phase breakdown; work is a single undifferentiated block.
- **1:** Phases exist but outputs or decision gates are missing; commitments extend beyond what’s controllable.
- **2:** Phases have concrete outputs and decision gates; commitments are limited to what’s within control.

## 4) Milestones + ownership (0–2)
- **0:** No milestones; or milestones are activities (“do design”) not deliverables.
- **1:** Milestones are deliverable-based but missing owners, dates, or dependencies; no RAG or confidence.
- **2:** Milestones are deliverable-based with owners, dates, dependencies, confidence, and RAG status.

## 5) RAG usefulness (0–2)
- **0:** No RAG system; or RAG exists but definitions are missing (what triggers amber/red?).
- **1:** RAG definitions exist but are subjective (“feels risky”); yellow/red lack explicit asks or deadlines.
- **2:** RAG definitions are action-oriented; yellow/red include explicit asks/decisions with deadlines.

## 6) Governance cadence (0–2)
- **0:** No review cadence; status is ad hoc or only on request.
- **1:** Weekly review exists but agenda is vague; escalation path or decision logging is missing.
- **2:** Weekly review agenda + escalation path + decision logging are all defined.

## 7) Scope protection (0–2)
- **0:** No scope control; new scope enters freely with no trade-off.
- **1:** Non-goals or cut list exist but freeze points are missing; “trade, don’t add” is stated but not operational.
- **2:** Non-goals + cut list + freeze points exist; change control rule is operational with a named decision owner.

## 8) Stakeholder comms (0–2)
- **0:** No comms plan; stakeholders get no proactive updates.
- **1:** Templates exist but don’t use correct commitment language; or “what changed” / “decision needed” sections missing.
- **2:** Templates use correct commitment language; updates include “what changed” + “decision needed by when”.

## 9) Risk management (0–2)
- **0:** No risks identified; or risks listed with no owners or mitigations.
- **1:** Risks captured but early warning signals missing; open questions lack time bounds.
- **2:** Risks and early signals captured with owners/mitigations; open questions and next steps are actionable with time bounds.

## 10) AI/ML outer loop (0–2, conditional)
- **0:** AI/ML is involved but demo vs production work is not separated; eval/safety/monitoring missing.
- **1:** Demo vs production separation acknowledged but eval, safety, or rollout steps are incomplete.
- **2:** Demo vs production separation is explicit; eval/safety/monitoring/rollout all included with owners.
- If not applicable: mark as N/A and don’t count it.
