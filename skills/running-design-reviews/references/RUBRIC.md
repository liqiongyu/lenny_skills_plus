# Rubric (Score 1–5 per category)

Use this to score the Design Review Pack. Target: **≥24/30**.

## 1) Decision clarity
1 = No decision; “get feedback” only
2 = Decision vaguely implied but not stated as a sentence; in/out scope unclear
3 = Decision exists but still fuzzy
4 = Decision statement is specific; in-scope is clear but out-of-scope feedback is not explicitly deferred
5 = Clear decision statement + explicit in/out scope

## 2) Preparation quality
1 = No pre-read; unclear context
2 = Pre-read exists but missing key elements (problem statement, success criteria, or artifact links); reviewers would need a verbal walkthrough
3 = Some context; artifacts exist but are hard to review
4 = Brief covers problem, user, constraints, and links; minor gaps in "how to review" instructions
5 = Brief is reviewable async; links/states/constraints are clear

## 3) Feedback quality (structure + hierarchy)
1 = Preference wars / minutiae-first
2 = Feedback is listed but not structured as observation+impact; Value/Ease/Delight hierarchy is not enforced
3 = Some structure but inconsistent
4 = Most feedback follows observation+impact format; hierarchy is mostly enforced with occasional minutiae leakage
5 = Feedback captured as observation+impact and prioritized Value->Ease->Delight

## 4) Synthesis + prioritization
1 = Long list; no priorities
2 = Some grouping of feedback but no severity ranking or impact assessment; duplicate comments not merged
3 = Priorities exist but not tied to impact/risk
4 = Top issues identified with severity and impact; most conflicts resolved but some lack rationale
5 = Top issues + severities + rationale are clear; conflicts resolved via goals/constraints

## 5) Decisions + tradeoffs captured
1 = Decisions left implicit
2 = Some decisions stated but rationale is missing; tradeoffs not documented; no owners or dates assigned
3 = Some decisions captured; tradeoffs missing
4 = Decisions have rationale and owners; most tradeoffs documented; some due dates missing
5 = Decision record includes rationale + tradeoffs + owners/dates

## 6) Follow-through
1 = No owners/dates; no next review plan
2 = Some owners assigned but action items are vague; no follow-up message drafted; next review not planned
3 = Owners exist; weak next step clarity
4 = Action items have owners and dates; follow-up message drafted; next review timing identified but not scheduled
5 = Action plan is executable; follow-up message + next gate scheduled

## Interpretation
- **24–30:** High-quality review; proceed.
- **18–23:** Acceptable but needs tightening (usually decision clarity or prioritization).
- **≤17:** Re-run with better prep and clearer requested feedback.
